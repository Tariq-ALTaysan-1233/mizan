# قرارات المنتج المعتمدة
- الاسم: ميزان. اللغة في الإصدار الأول: العربية فقط واتجاه RTL.
- العملة الأساسية: الريال السعودي SAR.
- المصروفات توزع بالتساوي على المستحقين، وتثبت الحصص وقت التسجيل.
- الملفات الشخصية متعددة تحت حساب دخول واحد، مع مشاركة اختيارية للحسابات والمصروفات.
- مشاركة الحساب للعرض افتراضياً، مع إمكانية منح صلاحية استخدامه للدفع.
- الرصيد الافتتاحي يسجل كرصيد بداية وليس دخلاً أو مصروفاً.
- فصل المصروف عن الدفعة والتسوية.
- دعم النقد والبنوك والمحافظ والبطاقات مسبقة الدفع/المرتبطة برصيد.
- لا وحدة دخل أو رواتب أو ميزانيات أو ديون بطاقات ائتمانية في الإصدار الأول.
- الحذف إلى سلة المحذوفات، والحذف النهائي للمسؤول مع سجل تدقيق.
- نسخ احتياطي يومي، واستيراد Excel مع تمييز المكرر.
- OCR للمراجعة البشرية قبل اعتماد بيانات الفاتورة.
- الجرد اليومي والشهري واليدوي، والفروقات لا تعدل تلقائياً.
- تعارض المزامنة يحتفظ بالنسختين للمراجعة.

## ضوابط مالية مضافة في الترحيلة 002
- الرصيد الافتتاحي يقابل حساب الأرصدة الافتتاحية (حقوق) وليس حساب إيرادات.
- تقسيم حصص المصروف يتم مرة واحدة على الأعضاء النشطين وقت التنفيذ، بدقة الهللة، مع ترتيب UUID ثابت لتوزيع الباقي.
- اعتماد قيد اليومية يمر عبر دالة تتحقق من تساوي المدين والدائن.
- الطلبات المالية يجب أن تستخدم `idempotency_keys` لمنع تكرار التسجيل عند إعادة المحاولة.
- هذه الدوال نواة قاعدة بيانات، وليست بديلاً عن صلاحيات API وRLS واختبارات التكامل.
