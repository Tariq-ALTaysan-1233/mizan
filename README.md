# ميزان

نقطة انطلاق تقنية لنظام عربي لإدارة المصروفات والجرد والتسويات المالية.

## المتطلبات
- Node.js 20 أو أحدث
- PostgreSQL 16 أو أحدث

## التشغيل المحلي للواجهة
```bash
npm install
npm run dev
```
ثم افتح http://localhost:3000

## قاعدة البيانات
نفّذ الترحيلات بالترتيب على قاعدة بيانات PostgreSQL جديدة:
1. `database/migrations/001_initial.sql`
2. `database/migrations/002_financial_controls.sql`

## ملاحظات مهمة
- هذا مستودع تأسيسي، وليس نظاماً إنتاجياً جاهزاً.
- لا توجد بعد مصادقة فعلية أو API أو عمليات مالية مكتملة.
- يجب إضافة اختبارات، وسياسات عزل البيانات، والتحقق المحاسبي داخل معاملات قاعدة البيانات قبل استخدام بيانات حقيقية.
- العملة الأساسية SAR، وتخزن المبالغ بدقة عشرية.
- لم تُختبر الترحيلات على خادم PostgreSQL في بيئة الإنشاء الحالية.

## الترحيلات
تتضمن الترحيلة الثانية كيانات الاستيراد والتصدير وOCR والنسخ الاحتياطي والمزامنة والجرد، ومفاتيح منع تكرار الطلبات، ونواة دوال لتوزيع الحصص بالتساوي بالهللة وترحيل الرصيد الافتتاحي والتحقق من توازن القيد.
